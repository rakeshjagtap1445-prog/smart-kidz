SMART KIDZ PWA V2
New in V2: language switching (Hindi/Marathi/English), browser speech pronunciation buttons, owl teacher character, ABC sounds, memory game, and five activity progress tracking.

UPDATE YOUR EXISTING GITHUB REPOSITORY:
1. Open your smart-kidz repository.
2. Upload/replace the files in the repository root: index.html, style.css, app.js, manifest.json, sw.js, icon-192.png, icon-512.png, README.txt.
3. Commit changes to main.
4. Wait for GitHub Pages deployment.
5. Reopen the app online. If the old version remains, close the app fully and refresh the website. Service worker cache is versioned as smart-kidz-v2.

IMPORTANT:
- ₹99 checkout is still a demo; it does not collect payment.
- Speech depends on voices supported by the Android browser/device.
- Adult supervision is recommended. Activities are playful supplements, not assessments.
