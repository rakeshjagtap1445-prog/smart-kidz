SMART KIDZ PWA - FIRST DEMO
This is a starter prototype, not a payment-ready commercial app.

HOW TO TEST ON ANDROID:
1. Upload the contents of this ZIP to an HTTPS static host (for example, a free static hosting service).
2. Open the HTTPS website in Chrome on Android.
3. Use Chrome menu (three dots) > Add to Home screen / Install app.
4. Test free Colour Hunt, Count & Learn, Shape Match and parent tips.

IMPORTANT:
- Payment is NOT connected. The ₹99 button is a demo paywall and does not charge users.
- Before accepting money, add a secure payment gateway checkout and server-side payment verification. Never store card/UPI credentials yourself.
- PWA installation requires HTTPS (localhost is an exception for development).
- Test all content and translations with parents/early-childhood educators before commercial release.
- Icons are generated simple brand placeholders.
